# topo_mod

Fabric mod for Minecraft 26.3. One jar runs on both client and dedicated server.

## Develop

- `./gradlew runClient` - launch a dev client
- `./gradlew runServer` - launch a dev dedicated server
- `./gradlew build` - build the jar into `build/libs/` (use the non-`-sources` jar)

Requires JDK 25.
